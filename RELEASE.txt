Новая версия Vexx Learn (для тебя)
==================================

Один клик — всё само (+1 к patch: 0.2.1 → 0.2.2):

   BUMP-RELEASE.bat

Делает: bump package.json → release:pack (manifest appVersion!) → build exe → commit → push → tag vX.Y.Z

Важно: в manifest на GitHub должна быть та же appVersion, что в package.json.
Иначе у пользователей «уроки актуальны», а exe не видит обнову.
